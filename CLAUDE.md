# Dungeon Tasks

Личный RPG таск-менеджер Некита: Telegram-бот + PWA + хоткей на маке. Один Python-процесс под launchd, SQLite `data/dungeon.db`, без LLM кроме 3-4 вызовов Claude в неделю на планирование.

## Команды
- `scripts/setup.sh install | restart | status | logs | stop | url`. После правки `.env` или `config/*.yaml` обязательно `restart`.
- Тесты: `uv run pytest` (около 207). Гнать перед любой правкой логики.
- Пробный прогон ритуалов: `uv run python scripts/ritual_dryrun.py`.

## Где что
- `dungeon/`: код (парсер задач, игра, тикер, коуч `coach.py`, офлайн-вердикт `offline.py`). `config/`: чек-листы, ключевые слова ритуалов, мотивация.
- Хроника недели пишется в Obsidian `Продуктивность и привычки/Хроники подземелья/`. Цели пользователя: `Продуктивность и привычки/Мои цели.md`.

## Правила
- Не менять схему БД без миграции и теста. Не трогать `data/` и `.env`.
- Идеи для коуча (буфер 70/30, лёгкий квест на плохой день, режим «застрял») лежат заметкой в Obsidian «Творческие идеи», в код вносить отдельной задачей с тестами.
